# Included font licenses

- `JetBrainsMono-OFL.txt`: official JetBrains Mono OFL text from https://raw.githubusercontent.com/JetBrains/JetBrainsMono/master/OFL.txt; covers the unmodified JetBrains Mono NL fonts adapted from SourceGit.
- `Inter-OFL.txt`: official Inter OFL text from https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt; covers the Inter font embedded by Avalonia.Fonts.Inter.

The packaging script also copies the exact redistributed .NET runtime package's `LICENSE.TXT` and `THIRD-PARTY-NOTICES.TXT` from the restored NuGet runtime pack into the release `licenses/` directory.
